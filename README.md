#JSONProject

Pré-requesitos:
  - Preciso instalar o IntelliJ IDEA: https://www.jetbrains.com/idea/download/?section=windows

Testar o projeto: 
  - Clonar o projecto
  - No IntelliJ IDEA, ir a File e depois Open..., e a seguir procurar a diretoria onde está o projeto.
  - Fazer a configuração do JDK para a versão 21 e mudar o VCS na diretória de mapeamento de Git para none.
